## 🇷🇺 Русский

### О нас

**eklimov-dev.ru** — проекты и инструменты для разработки программного обеспечения, автоматизации и администрирования IT-инфраструктуры.

Основные направления:

- **Backend** — REST API, микросервисы и интеграции.
- **Automation** — автоматизация Windows и Linux.
- **Monitoring** — диагностика и мониторинг систем и сетей.
- **DevOps** — развёртывание и сопровождение сервисов.

### About

**eklimov-dev.ru** hosts software projects and utilities focused on development, automation, and IT infrastructure management.

- **Backend** — REST APIs, microservices, and integrations.

- **Monitoring** — system and network diagnostics and monitoring.
- **DevOps** — service deployment and infrastructure maintenance.
